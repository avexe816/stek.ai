# 料金プラン方針（Base / Pro / Enterprise）

`docs/stek_homepage_repositioning_guide.md` の続き。サイトの `/pricing.html` と
`data/site.json` の `pricing` は、この文書を正として書く。

---

## 1. 前提

清掃管理は、PMSよりも現場の課題に直結する。商機があるのは、清掃進捗・点検・再清掃・
忘れ物・不具合報告といった、毎日発生してPMSには残らない業務である。料金の設計も、
この毎日の業務を止めないことを最優先にする。

---

## 2. プランの数

標準製品として売るのは **Base と Pro の2系統だけ**。

**Enterprise は3つ目の製品ではない。** Pro に、SLA・セキュリティ要件・多施設管理・
個別連携・導入支援を加えた **個別契約のレイヤー** として扱う。サイト上でもそのように
書く（「別の製品ではありません」）。

三つの別製品・別コードベースを作らない。単一のマルチテナント構成のまま、
`plan_entitlements`、機能フラグ、利用上限、権限で差をつける。

この構成から出てくる顧客向けの言い方は次のひとつだけ。ほかの実装用語は公開文言に出さない。

> プランの違いは設定の切り替えで反映されます。途中でプランを変えるときに、
> データの移行やつくり直しは必要ありません。

---

## 3. 各プランの位置づけ

| プラン | 主な対象 | 提供価値 | 価格案 |
| --- | --- | --- | --- |
| Base | 小規模なホテル・旅館・民泊 | 清掃状況の可視化。紙・電話・チャットの削減 | 施設あたり月額 4,800〜4,980円／30室程度を含む |
| Pro | 50〜200室のホテル、清掃受託会社 | 自動・一括割当、点検・再清掃、人員効率・原価分析、PMS連携オプション | 月額 14,800円／50室程度を含む |
| Enterprise | チェーン本部、運営会社、大型清掃会社 | 多施設横断、BI、SSO、SCIM、監査、個別連携、SLA・導入支援 | 月額 50,000円または120,000円からの個別見積 |

公開サイトに載せるのは**目安のレンジだけ**にする（「月額 5千円前後」「月額 1万円台半ば」
「月額5万円台から」）。ProofKeeping は先行導入のご相談を承っている段階であり、
確定価格として掲載しない。確定した金額はお見積りで出す。

---

## 4. 削ってはいけないもの

現場で最低限必要なものは **Base でも提供する**。

- 多言語（7言語）
- スマートフォン利用
- 写真報告
- 基本チェックリスト
- オフライン対応

上位プランは、現場の必須操作を削って差をつけるのではなく、**運営・管理側のレバレッジ**で
価値を作る。具体的には、割り当て・点検・集計・権限・複数施設・連携。

料金表を書くときの判断基準：

- その行が「清掃スタッフが毎日触る操作」なら、Base も「含む」。
- その行が「責任者・本部の手間を減らすもの」なら、Pro 以上。
- その行が「契約・規程・セキュリティに属するもの」なら、Enterprise の個別契約。

---

## 5. 提供状況の書き方

料金表のセルに使える値は、次の5つだけ（管理画面では選択式）。

| 値 | 意味 |
| --- | --- |
| 含む | そのプランの標準に入っている |
| オプション | 追加でご契約いただく |
| 個別のご相談 | Enterprise の個別契約で承る。標準機能としては提供していない |
| 準備中 | まだお使いいただけない |
| — | 含まない |

`docs/stek_homepage_repositioning_guide.md` §11 の禁止事項をそのまま引き継ぐ。とくに、

- SSO・SCIM・監査ログ・BI・SLA を「含む」と書かない（個別のご相談）。
- 人員・原価の分析は、STEK OPS 側で構想している範囲と混ぜない。
- 機能ごとの正式な提供状況は `/products/proofkeeping/` の `status_rows` が唯一の出どころ。
  料金ページはそこへリンクするだけで、独自に別の状況を書かない。

---

## 6. サイト上の置き場所

- `/pricing.html`（`data/site.json` の `pricing`）— プランと表の本体。
- ヘッダーメニューとフッターの「製品・サービス」列に「料金」を置く。
- `/products/proofkeeping/` の「料金」節は、考え方だけを書き、料金ページへリンクする。
- トップページは製品訴求のまま。情報量配分（ProofKeeping 35% / STEK OPS 30% /
  Web・IT支援 15%）を崩さないため、料金の段は置かない。
- STEK OPS の料金は載せない。構想段階であることをFAQで明示する。

---

## 7. 受入条件

- Base と Pro が標準、Enterprise が個別契約であることが読んで分かる。
- Base に、多言語・スマホ・写真・チェックリストが含まれていることが分かる。
- 掲載金額が目安であり、確定価格ではないことが分かる。
- 未実装の機能が「含む」と書かれていない。
- 清掃会社が契約主体になれることが書かれている。
- ライト・ダーク両モードで表が読める。
- スマートフォンで表が横スクロールにならない。
- 料金ページの内容が管理画面から編集できる。

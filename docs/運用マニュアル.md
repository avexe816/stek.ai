# stek.ai サイト 運用マニュアル

このサイトは、**日本語の原稿だけを直せば、英語・簡体中文・繁體中文・韓国語が自動で作られる**
仕組みになっています。編集は管理画面から行い、保存すると数分で公開されます。

---

## 1. 管理画面に入る

1. ブラウザで `https://stek.ai/admin` を開きます。
2. メールアドレスとパスワードを入力します。
   - メールアドレス: 登録済みのもの（初期設定は `ukh816@gmail.com`）
   - パスワード: 別途お渡ししたもの
3. ログインすると編集画面が開きます。

> パスワードを変えたいときは Cloudflare の管理画面で環境変数 `ADMIN_PASSWORD` を書き換えてください。

---

## 2. 文章を直す

左のメニューでページを選び、入力欄を直すだけです。

- 入力欄の下にオレンジの点が付いたら「まだ保存していない変更がある」印です。
- **改行はそのまま画面に反映されます。**「ヒーロー：大見出し」のように改行位置が
  見た目を左右する項目は、1 行が長くなりすぎないようにしてください。
- 「上級者向け：id」「上級者向け：no」は、ページ内リンクや番号表示に使う記号です。
  意味が分からない場合は触らないでください。

### カード形式の項目（サービス、よくあるご質問、条文など）

見出しの行をクリックすると開きます。右側のボタンで

| ボタン | はたらき |
| --- | --- |
| ↑ ↓ | 並び順を入れ替える |
| ⧉ | そのカードを複製する（似た項目を足すとき便利） |
| × | そのカードを削除する |

いちばん下の「＋ 追加」で新しいカードを作れます。

---

## 3. 訳文を直す

各入力欄の右にある **「訳文」** を押すと、その日本語に対応する 4 言語の訳が出ます。

- そのまま書き換えて保存すると **「人工確認済み」** になり、以後は自動翻訳で上書きされません。
- 元に戻したいときは **「日本語から作り直す」** を押してから保存すると、AI が翻訳し直します。
- 日本語を書き換えた場合は「別の文章」として扱われるため、保存時に自動で翻訳されます。
  固有名詞や言い回しにこだわる場合は、公開後に訳文を確認してください。

---

## 4. 写真を差し替える

左メニューの **「写真」** を開き、差し替えたい枠の「ファイルを選ぶ」から画像を選びます。

- JPEG・PNG・WebP のどれでも構いません。ブラウザ側で自動的に軽い WebP に変換します。
- 横長（3:2 前後）の写真がきれいに収まります。**横 1600px 以上**を推奨します。
- 人物の顔や商標（車のロゴなど）が写り込んでいないか、事前にご確認ください。

---

## 5. 保存して公開する

1. 右下の **「保存して公開」** を押します。
2. 変更内容の一覧が出るので確認し、必要ならメモ（変更理由）を書いて確定します。
3. 保存すると、
   - 足りない訳文が AI で自動生成され、
   - GitHub に記録が残り、
   - Cloudflare が自動でサイトを作り直します。
4. 左下の「公開状況」が **公開中… → 公開済み** に変わったら反映完了です（通常 2〜4 分）。

> 「ほかの方が先に保存しました」と出たときは、別の端末で編集した内容が先に保存されています。
> ページを再読み込みしてから、もう一度編集してください。

---

## 6. お問い合わせフォーム

- 送信されたお問い合わせは `noreplay@stek.ai` から **info@stek.ai** に届きます。
- 迷惑メール対策として、隠しフィールドと文字数制限を入れてあります。
- 届かない場合は、Cloudflare の環境変数 `SMTP_PASS` が有効か、
  受信側の迷惑メールフォルダに入っていないかを確認してください。

---

## 7. 困ったときは

| 症状 | 確認すること |
| --- | --- |
| 保存できない | ログインが切れていないか（12 時間で自動的に切れます） |
| 公開されない | GitHub → Actions、または Cloudflare → Pages のビルド履歴でエラーを確認 |
| 訳が日本語のまま出る | その文章の訳がまだ無い状態です。「訳文」から手入力するか、保存し直してください |
| フォームが送れない | Cloudflare の環境変数（SMTP_*）を確認 |

技術的な設定値は、リポジトリの `README.md` にまとめてあります。
